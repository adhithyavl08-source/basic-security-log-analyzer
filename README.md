
# Basic Security Log Analyzer

A beginner-friendly Python cybersecurity project that analyzes system log files and identifies suspicious login activities.

## About

The Basic Security Log Analyzer is designed to monitor and analyze log entries to detect repeated failed login attempts and suspicious activities.

## Features

- Reads log files
- Detects failed login attempts
- Identifies repeated failures from IP addresses
- Generates basic security warnings
- Displays analysis results

## Technologies Used

- Python
- Regular Expressions (Regex)
- File Handling
- Command-Line Interface (CLI)

## Project Files

- `log_analyzer.py` - Main Python program
- `auth.log` - Sample log file used for analysis

## How It Works

The program reads log entries, checks for failed login attempts, counts the attempts associated with IP addresses, and displays warnings when repeated failures are detected.

## Purpose

This project was created to understand basic security log analysis, system monitoring, and suspicious activity detection.
